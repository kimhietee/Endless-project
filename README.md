Hello!!! Source code of my game Fighting Kimhie - Endless

This is my Ex-Prototype from Fighting Kimhie game I've been working on.

Fighting Kimhie - Endless is a mobile version of my Pygame project I've been working on using Kotlin and KorGE Forge and VS code as my IDE.
The game works similar to my main game, but you can choose a hero to play on, and defeat enemies in waves endlessly until you breath your last! You can then share your score to other people with my login system implemented using Firebase as my backend database for my game.

This game was made for my personal project, and I do not own any assets I used for this game.
